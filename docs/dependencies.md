# Источники и лицензии

Проект: Apache-2.0, полный текст в LICENSE. Прямая зависимость eframe 0.36.2: MIT OR Apache-2.0. Собственные geometry/model: Apache-2.0. Cargo.lock фиксирует граф.

[Инвентарь](dependency-inventory.csv) получен из cargo metadata --locked для aarch64-apple-darwin. В нём записаны версии, SPDX, источник и upstream прямых и транзитивных зависимостей. При обновлении графа инвентарь регенерируется.

MIT/Apache-2.0/BSD/ISC/Zlib/Unlicense разрешают распространение при соблюдении требований уведомлений. В выражениях OR выбирается совместимая разрешительная лицензия; slash-обозначения MIT/Apache-2.0 в старых manifest трактуются согласно текстам upstream. Unicode-3.0 относится к данным Unicode; OFL-1.1 и Ubuntu-font-1.0 — к шрифтам. Шрифты распространяются без модификации и с соответствующими уведомлениями. Зависимость с Apache-2.0 OR GPL-2.0-only используется по Apache-2.0.

Проверка окончательных notices выполняется при упаковке этапа 18; инвентарь не заменяет тексты лицензий. Проприетарных каталогов на этапе 1 нет. Тестовые профили будут аналитическими с документированным происхождением.

## Особенность текущего macOS-хоста

Системный линкер не читает архитектуру arm64e.x1 из SDK 27. Для локальной сборки проверяется установленный SDK 26.5 через SDKROOT. Это локальная настройка процесса, без изменения системного SDK или исходников зависимостей.

Геометрические зависимости этапа 2: truck-modeling 0.6.0, truck-topology 0.6.0, truck-meshalgo 0.4.0, truck-shapeops 0.4.0 — Apache-2.0. Последняя имеет документированный локальный patch; см. vendor/truck-shapeops/PATCH.md. Инвентарь обновлён по конечному графу этапа 2.

Этапы 3–5 используют serde/serde_json (MIT OR Apache-2.0) и sha2 0.11.0 (MIT OR Apache-2.0). Полный инвентарь обновлён до графа этапа 5; выбран Apache-2.0 там, где доступен.

Этап 6: glam 0.34.1 (MIT OR Apache-2.0) для f64-камеры; egui/egui-wgpu 0.36.2 и wgpu 30.0.1 (MIT OR Apache-2.0) для GPU; image 0.25.10 (MIT OR Apache-2.0) для PNG framebuffer. Прямые версии закреплены; инвентарь обновлён из cargo metadata --locked.
