# Транзакции и отмена

Document предоставляет модель только для чтения. Create, Delete, Transform, ChangeProperty, ReplaceElement и RenameProject исполняются через transact. Команды сначала применяются к рабочей копии; вся модель проверяется перед публикацией. Ошибка сохраняет исходную модель, ID-счётчик, ревизию, undo и redo.

История хранит только изменённые записи до/после и метаданные, а не полный проект на каждую операцию. Текущий предел — 256 транзакций. Undo/redo восстанавливают точные ID, значения, next_id и ревизию; независимый монотонный serial событий не откатывается. SHA-256 вычисляется из канонического JSON с упорядоченными картами. Тест из 100 команд сверяет исходный и конечный хеши после полной отмены и повтора.

Delete имеет обязательную политику. RejectDependencies отклоняет удаление объекта с зависимостями. Cascade удаляет зависимые элементы материала/профиля; удаление сборки или её главного элемента удаляет всю принадлежащую ветвь. Удаление второстепенной детали убирает её из состава. Внешний родитель теряет ссылку на удалённую дочернюю сборку. Полная валидация запрещает висячие ссылки.

ChangeEvent включает непосредственно изменённые ID, зависимые элементы каталогов, сборки и предков сборок в старой и новой модели. DependencyCache записывает ID источников каждой записи; событие удаляет связанные записи, сохраняя остальные. Позже renderer/drawings/numbering используют этот общий механизм.

Текущая транзакционная проверка использует одну рабочую копию проекта. Это обеспечивает атомарность; её стоимость на больших моделях измеряется и оптимизируется в этапе производительности без ослабления проверки.
