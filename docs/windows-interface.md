# Интерфейс Windows

Приложение использует Segoe UI и масштабирование экрана Windows. При обычном
запуске окно развёрнуто на рабочую область экрана; доступны штатные кнопки
сворачивания, разворачивания и закрытия. Имя проекта и звёздочка несохранённых
изменений видны в заголовке окна. Полный путь доступен в подсказке к имени файла.

В меню «Файл» и на клавиатуре:

| Действие | Сочетание Windows |
|---|---|
| Создать / открыть / сохранить | Ctrl+N / Ctrl+O / Ctrl+S |
| Сохранить как | Ctrl+Shift+S |
| Отменить / повторить | Ctrl+Z / Ctrl+Y (также Ctrl+Shift+Z) |
| Копировать объекты / вставить | Ctrl+C / Ctrl+V |
| Копировать по точкам | Ctrl+Shift+D |
| Поиск в модели / каталог компонентов | Ctrl+F / Ctrl+Shift+F |
| Поиск команд | Ctrl+P |
| Переключить 3D / плоский вид | Ctrl+Shift+3 |
| Импорт IFC / панель видов | Ctrl+I / Ctrl+Shift+I |
| Нумерация / контекстная панель | Ctrl+K / Ctrl+Shift+K |
| Свойства / менеджер документов | Ctrl+L / Ctrl+Shift+L |
| Добавить / убрать объект клавиатурным курсором | Ctrl+Пробел |
| Подсказки команд ленты | Alt (нажать и отпустить) или F10 |
| Полная справка | F1 |

«Открыть» и «Сохранить как» показывают системные диалоги. Новый проект при первом
сохранении предлагает выбрать имя и папку. Отмена диалога не меняет проект.
«Сохранить как» создаёт отдельный файл и переключает последующие сохранения на
него; при ошибке записи прежний путь остаётся действующим.

В текстовых полях Ctrl+A/C/V/Z/Y относятся к тексту, а не к объектам модели.
Alt+Пробел оставлен системному меню окна Windows. Сочетания macOS с Command
продолжают работать на Mac.

3D-вид рисуется в физических пикселях экрана. Для рёбер деталей автоматически
включается MSAA 4×, если видеокарта поддерживает его для цветового буфера и
буфера глубины; на остальных устройствах остаётся совместимый режим 1×.
Освещение дополнено мягким заполняющим светом, чтобы стенки и полки профилей
сохраняли читаемость с разных сторон. При увеличенном масштабе интерфейса
вкладки ленты прокручиваются по горизонтали, сохраняя место для модели.

Проверки адаптации: `windows_interface`, `keyboard_only`, `ui_shell`,
`ribbon_chrome`, `project_change`, `unsaved_close`.
