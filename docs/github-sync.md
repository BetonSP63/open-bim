# Выгрузки в GitHub

Пользователь разрешил создание публичного репозитория `BetonSP63/open-bim`. После каждого завершённого этапа выполняются четыре проверки из README, затем коммит и `git push origin main`. Первый коммит фиксирует завершённые этапы 1–6 и проверяемые инструменты этапа 7. Промежуточные рабочие сценарии не означают завершение этапа.

В репозиторий входят исходники, закреплённые зависимости, лицензии, документация и тестовые данные. Каталог сборки `target` исключён.
