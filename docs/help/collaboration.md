# Общая модель

Откройте «Управление → Совместная работа». Выберите общую папку на локальном
диске или сетевом ресурсе SMB/NFS, затем новый файл локальной копии
`.obim`. Для новой модели выберите пустую общую папку.

- «Создать общую модель» записывает текущий проект как первую ревизию.
- «Открыть общую модель» создаёт локальную копию последней ревизии.
- «Сохранить в общую модель» публикует правки с комментарием. Сочетание
  клавиш — Shift+⌘+M на Mac, Ctrl+Shift+M на Windows и Linux.
- «Получить изменения» объединяет общие изменения с локальными правками.
- «Проверить ревизии» показывает в строке состояния номер локальной базы
  и последней общей ревизии.
- «Освободить» снимает блокировки текущего инженера.

Файл `<имя>.obim.shared.json` хранит связь с общей папкой, имя инженера
и базу слияния. Держите его рядом с локальным `.obim`. При работе без
доступа к общей папке сохраняйте локальные изменения обычной командой
«Сохранить» и публикуйте после восстановления доступа.

## Как проверить на Mac

Создайте общую модель. Откройте ту же папку во второй копии программы
с другим файлом локальной копии. Измените разные детали и опубликуйте
обе правки. В первой копии получите изменения и проверьте обе детали и
номер общей ревизии.
