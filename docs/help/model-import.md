# Импорт моделей из других программ

Open BIM открывает модели других программ через IFC — открытый формат обмена
(ISO 16739), который умеют выгружать все распространённые программы
информационного моделирования. Собственные форматы коммерческих программ
закрыты: их структура не опубликована, а читать их разрешено только средствами
самих производителей. Поэтому путь один: в исходной программе сохранить модель в
IFC, в Open BIM — импортировать этот файл.

## Как импортировать

1. «Файл» → «Импорт IFC» (⌘I) или кнопка «Импорт IFC» на вкладке «Обмен».
2. Выберите файл `.ifc`.
3. Если модель пустая, файл открывается как новый проект. Если в модели уже есть
   объекты или сетка осей, содержимое файла добавляется к ним одним действием
   (отменяется ⌘Z).
4. В строке сообщения — итог: сколько балок, колонн, пластин и сборок
   импортировано, какие сечения сопоставлены с сортаментом ГОСТ, какие стали
   распознаны и что не импортируется.

## Что переносится

| Из файла | В Open BIM |
|---|---|
| Балки, колонны, связи (IfcBeam, IfcColumn, IfcMember и их StandardCase) | детали-профили |
| Пластины (IfcPlate) | пластины по контуру |
| Сечение в параметрах (двутавр, швеллер, уголок, трубы, прямоугольник) | сечение сортамента ГОСТ, если совпали размеры |
| Сечение контуром (полилиния, кривая из отрезков и дуг, с пустотами) | сечение ГОСТ по габариту и площади, иначе — прямоугольник или пластина по контуру |
| Общая геометрия типа (IfcMappedItem) | обычная деталь на своём месте |
| Материал (в том числе списки, наборы слоёв и профилей, материал типа) | сталь ГОСТ 27772 / 19281, если марка есть в названии («С255», «Сталь C345») |
| Сборки (IfcElementAssembly) | сборки; главная деталь — самая длинная |
| Отверстия и вырезы (IfcOpeningElement) | отверстия, вырезы и резы |
| Наборы свойств | свойства деталей «Набор.Свойство» |
| GUID | свойство «IFC GUID», сохраняется при обратном экспорте |

Единицы файла (мм, м, дюймы и др.) пересчитываются в миллиметры. Модель в
геодезических координатах (дальше 1 км от начала) при добавлении сдвигается к
началу координат на целое число метров; сдвиг указывается в сообщении.

## Как распознаются сечения

Сначала по размерам: двутавр 200×100×5,6×8,5 — это 20Б1 по ГОСТ 26020-83, как бы
его ни назвала исходная программа. Если размеры немного отличаются (округление,
средняя толщина полки), используется обозначение: «20Б1», «I20B1_26020_83»,
«Двутавр ГОСТ 26020-83:20Б1», «L100X8», «[20П», «Гн.150x100x6», «Труба 114x4.5».
Указанный в названии стандарт (26020, Р 57837, 8239 …) уточняет выбор между
одноимёнными сечениями. Сечение, заданное контуром, сравнивается по габариту
(в любом из восьми положений) и площади с допуском 6 %.

Иностранные сечения (HEA, IPE, W …) в сортаменте ГОСТ отсутствуют и остаются как
в файле — они перечисляются в сообщении. Замену на отечественный аналог
выполняет инженер.

## Что не импортируется

Стены, перекрытия, фундаменты, арматура, болты и прочие объекты перечисляются
в сообщении («Не импортируются: стены 12, …»). Тела, заданные сеткой
треугольников или гранями (Brep), а также срезы булевыми операциями пока не
восстанавливаются: деталь с таким телом пропускается или импортируется без
среза, о чём есть замечание.

## Как выгрузить IFC из исходной программы

Общие настройки, которые дают наилучший результат:

* версия **IFC2x3** (вид «Coordination View 2.0»), **IFC4** (вид «Design
  Transfer View») или **IFC4.3**; из IFC4.3 читаются и мосты, дороги и другие
  сооружения: балки, колонны и пластины внутри них импортируются, опорные
  части, трассы и дорожная одежда перечисляются в сообщении. Вид IFC4 «Reference View» хранит тела сеткой треугольников —
  он не подходит;
* геометрия — **выдавливанием (SweptSolid / «твёрдые тела по профилю»)**, а не
  Brep или сеткой;
* выгружать **параметрические профили**, если есть такая опция;
* выгружать **наборы свойств и материалы**;
* единицы — миллиметры (другие тоже читаются);
* для программ металлоконструкций: выгружать сборки (вложенность «сборка →
  детали»); для архитектурных программ: выгружать каркасные семейства
  (балки, колонны, связи) и, если есть, «ось» элементов.

Файлы `.ifczip` перед импортом распакуйте.
