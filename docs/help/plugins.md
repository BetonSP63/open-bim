# Плагины

Плагин — отдельная программа, которая по своим правилам добавляет или
меняет объекты модели: ряды колонн, лестницы, фермы, связи, типовые узлы
своего бюро. Программу не нужно встраивать в Open BIM: она запускается
отдельным процессом и отвечает шагами того же языка, что и макросы
(`docs/help/batch-api.md`).

## Папка плагина

Плагин — папка с файлом `plugin.json` и программой:

```json
{
  "name": "Ряд колонн",
  "kind": "model",
  "code": "КОЛ-РЯД",
  "description": "Колонны с равным шагом между двумя точками",
  "program": "open-bim-plugin-columns",
  "inputs": [
    { "name": "start", "type": "point", "prompt": "Первая колонна" },
    { "name": "end", "type": "point", "prompt": "Последняя колонна" }
  ],
  "attributes": [
    { "name": "count", "label": "Количество", "type": "number", "default": 4 },
    { "name": "profile", "label": "Профиль", "type": "profile", "default": "Гн 150×100×6" }
  ],
  "timeout_s": 30
}
```

| Поле | Смысл |
|---|---|
| `name` | имя, по нему плагин вызывается (до 64 символов) |
| `kind` | `model` (объекты модели), `connection` (соединение деталей), `drawing` (чертежи) |
| `code` | короткий код, не длиннее 22 символов |
| `program`, `args` | программа (путь от папки плагина или абсолютный) и её аргументы |
| `inputs` | что указывает пользователь, **не больше 10**: `point`, `points`, `part`, `parts` |
| `attributes` | параметры диалога: `number`, `text`, `profile`, `material`, со значением по умолчанию |
| `timeout_s` | предел времени одного запуска, 1–3600 с (по умолчанию 60) |

Плагины ищутся во вложенных папках каталога плагинов. Два примера с
исходниками: «Ряд колонн» (`crates/api/plugins/columns`,
`crates/api/src/bin/open-bim-plugin-columns.rs`) и «Оголовок колонны»
(`crates/api/plugins/column-cap`, `open-bim-plugin-column-cap.rs`) —
пластина на торце выбранной колонны, которая следует за колонной. Собранную
программу (`cargo build -p open-bim-api --release`) положите в папку
плагина.

## Как плагин работает

1. Open BIM проверяет входы и атрибуты по описанию (недостающие атрибуты
   берутся по умолчанию).
2. Программа запускается в папке плагина и получает на stdin JSON:
   `protocol` (сейчас 1), `plugin`, `inputs` (точка — `[x, y, z]`, деталь —
   её ID), `attributes` и `model` — текущую модель целиком.
3. Программа печатает в stdout `{"steps": [...]}` — шаги макроса — или
   `{"error": "сообщение"}`. Ненулевой код выхода и текст stderr
   показываются как ошибка.
4. Шаги проходят обычные проверки и ставятся в очередь **вместе**: если
   один не прошёл, не остаётся ни одного. Дальше — обычная фиксация.

Плагину доступны только правки модели и чертежей: вставка, изменение,
выбор, удаление, свойства, перенос, копирование, создание чертежа.
Фиксация, сохранение, экспорт и вызов других плагинов ему недоступны.
Программа, не уложившаяся в `timeout_s`, останавливается.

Плагин — обычная программа на компьютере: ставьте только плагины из
источников, которым доверяете.

## Плагин в модели и зависимость от входов

Каждый запуск оставляет в модели **размещённый плагин**: имя, входы,
значения атрибутов и список созданных объектов. Плагин зависит от своих
входных деталей:

- если входная деталь изменилась (перенос, профиль, длина), при фиксации
  плагин запускается снова с теми же входами и атрибутами, без повторного
  выбора; его изменения входят в **тот же шаг отмены**, что и правка
  детали;
- объекты, созданные заново, сохраняют ID по порядку создания (марки и
  чертежи не теряются); лишние старые удаляются, новые добавляются;
- атрибуты размещённого плагина можно изменить — плагин запускается снова;
- удаление входной детали удаляет плагин и всё, что он создал; созданную
  плагином деталь отдельно удалить нельзя (только каскадно, вместе с
  плагином);
- если плагин не найден или завершился ошибкой, старые объекты остаются,
  а ошибка показывается.

Плагину при повторном запуске модель передаётся без его прежних объектов.
Сам плагин не фиксирует изменения: фиксацию делает программа.

## Запуск в программе

Команда «Плагины» (палитра команд, ⌘P) открывает окно со списком плагинов.
Они ищутся в папке `plugins` рядом с файлом проекта, в
`~/Library/Application Support/Open BIM/plugins`, в папках переменной
окружения `OPEN_BIM_PLUGINS` (список через `:`) и в папке, указанной в
окне («Обновить» перечитывает папки).

1. Выберите плагин: под ним — описание, входы и атрибуты.
2. Точки вводятся как `x y z` в мм (`;` разделяет точки списка). Детали —
   ID через пробел; кнопка «Детали из выбора» заполняет их выбранными
   деталями (вход на одну деталь — только если выбрана одна).
3. Атрибуты показаны со значениями по умолчанию; «По умолчанию»
   возвращает их.
4. «Выполнить» запускает плагин в фоне на копии модели. Пока он работает,
   модель не меняется; Esc отменяет ожидание. Результат фиксируется
   **одним шагом отмены**, созданные объекты выделяются. Если модель
   успела измениться, результат отбрасывается — запустите плагин снова.
5. Выберите объект, созданный плагином: в окне появится «В модели: …» с
   его атрибутами. «Изменить» запускает плагин снова с новыми значениями.
6. Когда меняется входная деталь размещённого плагина, программа сама
   запускает его снова в фоне и добавляет результат к тому же шагу
   отмены.

## Запуск из макроса

```json
{ "plugins": ["plugins"],
  "steps": [
    { "run_plugin": { "plugin": "Ряд колонн",
        "inputs": { "start": [0, 0, 0], "end": [18000, 0, 0] },
        "attributes": { "count": 4 } } },
    { "commit": "Колонны по оси А" } ] }
```

`plugins` — папки с плагинами (по умолчанию `plugins` рядом с макросом);
по ним же находятся размещённые плагины, которые надо запустить снова при
`commit`.
Созданные плагином объекты становятся текущим выбором для следующих шагов.
