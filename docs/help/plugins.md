# Плагины

Плагин — отдельная программа, которая по своим правилам добавляет или
меняет объекты модели: ряды колонн, лестницы, фермы, связи, типовые узлы
своего бюро. Программу не нужно встраивать в Open BIM: она запускается
отдельным процессом и отвечает шагами того же языка, что и макросы
(`docs/help/batch-api.md`).

## Папка плагина

Плагин — папка с файлом `plugin.json` и программой:

```json
{
  "name": "Ряд колонн",
  "kind": "model",
  "code": "КОЛ-РЯД",
  "description": "Колонны с равным шагом между двумя точками",
  "program": "open-bim-plugin-columns",
  "inputs": [
    { "name": "start", "type": "point", "prompt": "Первая колонна" },
    { "name": "end", "type": "point", "prompt": "Последняя колонна" }
  ],
  "attributes": [
    { "name": "count", "label": "Количество", "type": "number", "default": 4 },
    { "name": "profile", "label": "Профиль", "type": "profile", "default": "Гн 150×100×6" }
  ],
  "timeout_s": 30
}
```

| Поле | Смысл |
|---|---|
| `name` | имя, по нему плагин вызывается (до 64 символов) |
| `kind` | `model` (объекты модели), `connection` (соединение деталей), `drawing` (чертежи) |
| `code` | короткий код, не длиннее 22 символов |
| `program`, `args` | программа (путь от папки плагина или абсолютный) и её аргументы |
| `inputs` | что указывает пользователь, **не больше 10**: `point`, `points`, `part`, `parts` |
| `attributes` | параметры диалога: `number`, `text`, `profile`, `material`, со значением по умолчанию |
| `timeout_s` | предел времени одного запуска, 1–3600 с (по умолчанию 60) |

Плагины ищутся во вложенных папках каталога плагинов. Пример с исходником
программы лежит в `crates/api/plugins/columns` и
`crates/api/src/bin/open-bim-plugin-columns.rs`; собранную программу
(`cargo build -p open-bim-api --release`) положите в папку плагина.

## Как плагин работает

1. Open BIM проверяет входы и атрибуты по описанию (недостающие атрибуты
   берутся по умолчанию).
2. Программа запускается в папке плагина и получает на stdin JSON:
   `protocol` (сейчас 1), `plugin`, `inputs` (точка — `[x, y, z]`, деталь —
   её ID), `attributes` и `model` — текущую модель целиком.
3. Программа печатает в stdout `{"steps": [...]}` — шаги макроса — или
   `{"error": "сообщение"}`. Ненулевой код выхода и текст stderr
   показываются как ошибка.
4. Шаги проходят обычные проверки и ставятся в очередь **вместе**: если
   один не прошёл, не остаётся ни одного. Дальше — обычная фиксация.

Плагину доступны только правки модели и чертежей: вставка, изменение,
выбор, удаление, свойства, перенос, копирование, создание чертежа.
Фиксация, сохранение, экспорт и вызов других плагинов ему недоступны.
Программа, не уложившаяся в `timeout_s`, останавливается.

Плагин — обычная программа на компьютере: ставьте только плагины из
источников, которым доверяете.

## Запуск из макроса

```json
{ "plugins": ["plugins"],
  "steps": [
    { "run_plugin": { "plugin": "Ряд колонн",
        "inputs": { "start": [0, 0, 0], "end": [18000, 0, 0] },
        "attributes": { "count": 4 } } },
    { "commit": "Колонны по оси А" } ] }
```

`plugins` — папки с плагинами (по умолчанию `plugins` рядом с макросом).
Созданные плагином объекты становятся текущим выбором для следующих шагов.
