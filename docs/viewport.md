# Трёхмерный вид

Запуск: `cargo run --locked -p open-bim-desktop -- --example`. Открытие проверенного формата проекта: `--open tests/fixtures/projects/steel-frame-v1.obim`.

Metal/wgpu рисует общие профильные сетки через instancing в отдельную текстуру с Depth32Float, затем помещает её в окно egui. Освещение Lambert; выбранный ID окрашен оранжевым. CPU-камера, BVH и пересечения треугольников используют f64. Позиции GPU переводятся в f32 относительно центра сцены; исходная модель не изменяется.

ЛКМ выбирает ближайшую видимую поверхность; ПКМ открывает контекстное меню. Колесо масштабирует к точке под курсором, СКМ перемещает вид, Ctrl/⌘ + СКМ вращает. Home вписывает модель, Shift+Пробел — выбранное. F запускает измерение. Стрелки перемещают вид, Ctrl+стрелки вращают на 15°, Shift+стрелки — на 5°; PgUp/PgDn меняют масштаб. В команде построения цифры начинают числовой ввод и не переключают вид. Полная памятка доступна по F1; поиск команд — ⌘P. Реестр клавиш: `crates/desktop/src/ui/commands.rs`.

Во время команды моделирования под лентой показаны текущий шаг и кнопка «Прервать» с клавишей из реестра команд. Для точечного ввода рядом объясняется, как указать точку мышью или координатами. Подсказка переносится, если ширины окна недостаточно. Кнопка использует ту же отмену, что и Escape: при открытом числовом вводе сначала закрывается ввод, затем команда.

Флажки объектов управляют общей hidden-маской CPU/GPU. Сечение Z сохраняет поверхности выше заданной высоты; общая нормаль/смещение поступают в shader discard и CPU picking. Это отсекающий вид без геометрических крышек и штриховки среза. Такая визуальная сетка не используется как точное тело для выпуска документации. Круглая труба отображается 128 сегментами; точность её B-rep не заявлена. Поддерживаются групповой выбор и переключатели выбора деталей, сборок, осей и уровней; подробности — в `docs/interaction.md`.

`--capture /absolute/path.png` запрашивает снимок framebuffer настоящего приложения и закрывает окно после записи. `--select 8` задаёт начальное выделение; `--section 1500` задаёт отсекающий вид. `--gpu-error-test` вызывает настоящую ошибку валидации wgpu (буфер больше лимита устройства), которую принимает обычный runtime-обработчик. Это проверка сообщения и сохранения модели в памяти, а не испытание физического отказа GPU.

Проверки: [результаты](../tests/viewport/VERIFICATION.md), [контрольный каркас](../tests/viewport/frame.png), [пустой проект](../tests/viewport/empty.png), [сечение](../tests/viewport/section.png), [ошибка GPU](../tests/viewport/gpu-error.png). Эти снимки относятся к раннему этапу разработки; сами по себе они не подтверждают текущую производительность на больших моделях. Нагрузку необходимо измерять на указанном оборудовании и контрольной модели.
