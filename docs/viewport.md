# Трёхмерный вид

Запуск: `cargo run --locked -p open-bim-desktop -- --example`. Открытие проверенного формата проекта: `--open tests/fixtures/projects/steel-frame-v1.obim`.

Metal/wgpu рисует общие профильные сетки через instancing в отдельную текстуру с Depth32Float, затем помещает её в окно egui. Освещение Lambert; выбранный ID окрашен оранжевым. CPU-камера, BVH и пересечения треугольников используют f64. Позиции GPU переводятся в f32 относительно центра сцены; исходная модель не изменяется.

ЛКМ выбирает ближайшую видимую поверхность. ПКМ вращает; СКМ либо Shift+ПКМ перемещает камеру; колесо меняет масштаб. F вписывает модель; 1–4 переключают изометрию, фронт, верх и правый вид. Стрелки вращают; Shift+стрелки перемещают; +/− меняют масштаб. Клавиатура работает при фокусе/наведении на viewport. Кнопки позволяют выполнить fit и переключить виды мышью.

Флажки объектов управляют общей hidden-маской CPU/GPU. Сечение Z сохраняет поверхности выше заданной высоты; общая нормаль/смещение поступают в shader discard и CPU picking. Это отсекающий вид без геометрических крышек и штриховки среза. Такая визуальная сетка не используется как точное тело для выпуска документации. Круглая труба отображается 128 сегментами; точность её B-rep не заявлена. Сейчас выделение одиночное.

`--capture /absolute/path.png` запрашивает снимок framebuffer настоящего приложения и закрывает окно после записи. `--select 8` задаёт начальное выделение; `--section 1500` задаёт отсекающий вид. `--gpu-error-test` вызывает настоящую ошибку валидации wgpu (буфер больше лимита устройства), которую принимает обычный runtime-обработчик. Это проверка сообщения и сохранения модели в памяти, а не испытание физического отказа GPU.
