# Проверка Open BIM под Linux

На Ubuntu x86_64 запустите `scripts/test-linux-package.sh`. Скрипт создаёт
переносимый архив и пакет Debian, проверяет контрольные суммы, содержимое
пакетов и отказ от перезаписи. Debian выбран для установки на Ubuntu,
где выполняется CI. Он позволяет проверить пакет через `dpkg-deb` и
регистрирует значок, пункт меню и MIME-тип без инструмента AppImage.

Тесты `crates/desktop/tests/startup.rs` проверяют выбор каталога документов и
одновременный первый запуск. Пакет, сценарий моделирования через Xvfb и
поведение Wayland, HiDPI и портала диалогов ещё требуют проверки на Linux.


Для сценария моделирования установите `xvfb`, `xauth`, Mesa Vulkan и
Python-пакеты `ifcopenshell` и `pypdf`. Запустите
`scripts/verify-linux-workflow.sh /путь/open-bim-desktop /путь/к/результатам`.
Папка результатов получит журнал, снимки экрана и вывод независимой проверки.
