# Гнутые детали

Единицы длины — миллиметры, углы в окне создания — градусы. На вкладке «Металл» рядом с балкой и пластиной находятся команды «Гнутая балка», «Полибалка» и «Гнутый лист». Начало задаёт положение локальной системы детали; траектории вводятся в её плоскости XY, второе направление сечения — вдоль локальной оси Z.

- **Гнутая балка:** предварительно выберите сплошной профиль обычным инструментом «Балка», затем откройте команду гнутой балки и выберите материал. Задайте центр, радиус оси, начальный угол и угол дуги либо включите «Задать дугу тремя точками» и введите три точки через точку с запятой. Точки не должны лежать на одной прямой.
- **Полибалка:** предварительно выберите сплошной профиль обычным инструментом «Балка», затем откройте команду полибалки, выберите материал и введите точки через точку с запятой и радиус скругления. Ноль оставляет острые изломы. Радиус должен помещаться на прилегающих участках. Явные пересечения оси и пересечения оболочек удалённых участков отклоняются; проверка оболочек консервативна и может отклонять допустимые сложные траектории.
- **Гнутый лист:** задайте материал, ширину вдоль сгиба, толщину, внутренний радиус, угол и длины прямых участков до точек касания. Сгиб является частью одной детали. Развёрнутая длина по средней поверхности равна `L1 + L2 + (R + t/2) · |угол|`, где угол выражен в радианах. Коэффициент средней поверхности принят равным 0,5; для конкретного материала и технологии его следует сверять с производством.

Значения наименования, материала и профиля выбираются при создании. Для изменения выберите гнутую деталь, откройте любую из трёх команд и нажмите «Загрузить выбранную деталь … для изменения», затем «Применить изменения». Изменение сохраняет положение, ориентацию и пользовательские свойства; доступна отмена. Кнопка «Создать как новую деталь» возвращает режим создания. Детали сохраняются в проекте и участвуют в нумерации и ведомостях; разные параметры гибки дают разные ключи нумерации. В ведомости для гнутого листа указывается ширина заготовки и развёрнутая длина.

## Проверка на Mac с Apple Silicon

Установите Rust версии из `rust-toolchain.toml` и инструменты командной строки разработчика. В корне проекта выполните:

```sh
cargo test --locked -p open-bim-geometry --test sweep
cargo test --locked -p open-bim-model --test swept
cargo test --locked -p open-bim-numbering --test swept
cargo test --locked -p open-bim-reports --test swept
cargo test --locked -p open-bim-ifc --test swept
cargo test --locked -p open-bim-nc --test swept
cargo test --locked -p open-bim-commands --test swept
cargo test --locked -p open-bim-drawings --test swept
cargo test --workspace --locked
cargo run --locked -p open-bim-desktop
```

Если установленный системный линкер не совместим с текущим SDK, можно задать путь к совместимому установленному SDK через `SDKROOT` перед запуском команд. На проверочном Mac использовался `/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk`; путь и версия зависят от локальной установки.

В приложении создайте по одной детали каждым из трёх способов, сохраните проект, закройте и откройте его снова. Выполните «Нумеровать» и откройте ведомости. Для листа с шириной 100, толщиной 10, прямыми участками 200 и 150, внутренним радиусом 30 и углом 90° развёрнутая длина составляет примерно 404,978 мм. Создайте второй лист с иным радиусом и убедитесь, что марки отличаются. Экспортируйте IFC и проверьте результат и сообщение экспорта. Создайте отдельные чертежи деталей: для балок формируются три вида, для гнутого листа — ещё и развёртка с габаритными размерами, границами зоны сгиба и осью. Проверьте PDF и DXF. Для указанного листа ось сгиба находится на расстоянии 227,489 мм от торца, зона сгиба — 200…254,978 мм. Измените радиус на 50 мм и обновите чертёж: длина станет 436,394 мм. Проверьте также отрицательный угол.

Экспортируйте NC: на каждую марку гнутой детали создаются файл `.nc1` раскроя заготовки и русская карта `.bend.txt`. Проверьте размеры контура, количество и материал. Для заготовки, у которой ширина больше развёрнутой длины, NC поворачивает контур длинной стороной по X; карта отдельно указывает координату оси сгиба в системе NC. В спецификации лист остаётся одной деталью.

## Точность и ограничения

Дуги скругления полибалки и контур сгиба листа аппроксимируются отрезками со стрелой не более 0,01 мм. Длина по дугам для ведомости и развёртка листа вычисляются аналитически; масса листа вычисляется по средней поверхности. Визуальная сетка и экспорт IFC являются приближением геометрии. Результат может отклоняться от идеальной дуги; для изготовления нужно согласовать допуски и коэффициент развёртки.

Заметание поддерживает сплошные стандартные профили; полые и пользовательские профили для новых балок пока не поддерживаются. Несимметричные профили с каталожной площадью отклоняются: для точной массы при гибке необходим центр тяжести, который каталог пока не хранит. Проверка проекта заново строит тела гнутых деталей и может занимать заметное время в больших моделях. Отверстия и вырезы на гнутых деталях пока не поддерживаются. Зеркальное отражение таких деталей также отклоняется. Общие параметры и пользовательские свойства хранятся вместе с деталью, параметры гибки изменяются в отдельном окне команды на вкладке «Металл».

Экспорт IFC4 передаёт тела гнутых деталей как триангулированную поверхность; параметры гибки и аналитические дуги в таком представлении не сохраняются. Импорт этого сеточного представления в приложение пока не поддерживается. Отчёт экспорта указывает число деталей, переданных сеткой.

Экспорт NC/DSTV содержит прямую заготовку до гибки с комментарием `DEVELOPED STOCK BEFORE BENDING` и отдельной картой гибки. Для балки длина заготовки равна длине оси, для листа — длине средней поверхности. Карта содержит радиусы, знаковые углы, точки траектории либо границы зоны сгиба. Это раскрой и геометрические данные гибки; технологические припуски, пружинение и программа управления гибочным станком не включены. Для острых изломов полибалки карта явно указывает отсутствие радиуса.

Чертёж отдельной гнутой детали формируется в A3: три вида формы с габаритами, радиусом, углом, материалом и массой; у листа добавляется развёртка. Автоматические значения выводятся с точностью до 0,001 мм, геометрия сформированного тела сохраняет указанную выше погрешность аппроксимации. Развёртка пересчитывается после изменения параметров модели. Положение видов и графику можно настроить в редакторе чертежа; направление проекции развёртки фиксировано. Перед выпуском сверяйте технологические данные с производством.
