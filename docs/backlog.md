# Бэклог: типовой рабочий процесс и удобство (2026-10-20, обновлено 2026-10-30)

Цель: инженер-конструктор работает в Open BIM по привычному промышленному стандарту КМД,
и не упирается в мелкие неудобства. Источники: `docs/final-audit.md`,
`docs/interaction.md` (раздел «not implemented»), `docs/parity.csv`.

Порядок: сначала то, что инженер делает каждую минуту, потом то, без чего нельзя
выпустить реальный проект, потом обмен и платформы.

## Сделано после пунктов 1–12 (PR #29–#72)

- Узлы и детали: сдвоенный профиль, фаски углов пластины, обработка поверхности (#30); опорный столик и подбор узлов по профилю (#34); свои компоненты по формулам (#35); подгонка фаской (#52).
- Проверка и группы: запрос объекта, сравнение деталей, секущая плоскость (#31); группы объектов и представление (#32); контрольные номера и ведомость швов (#33).
- API и плагины: объектный API и пакетный режим (#36, #37), плагины отдельным процессом, окно «Плагины», зависимые плагины (#38–#40, #42).
- Интерфейс по эталонной программе: лента, сетка, панель свойств, нижняя панель, управление, правка, построения, вид, чертежи, комплексный чертёж (#41, #43–#51, #55); затем шапка панели свойств, лента, 3D-вид и шрифт (#62, #65); окно «Выбор профиля» (#64).
- Поверхности и диспетчер разбивок (#53), преобразование объектов IFC (#54), параметры модели и связанные размеры (#57).
- Расчётная модель: вкладка «Анализ» без расчёта (#56).
- Бетон, армирование и опалубка — основа без ГОСТ-форм и чертежей КЖ (#58–#60); формы, элементы и добавленный материал (#61).
- Чертёж: новые виды и разрезы в открытом чертеже (#63).
- Сварка по ГОСТ (#66), пользовательские и сварные сечения (#67).
- Параметрические семейства: плоскости, формулы, типоразмеры, вложенные, в спецификации и IFC (#68–#72, `docs/families.md`).

## Дальше: план выпуска 1.0 (2026-10-30)

Порядок этапов: 0 подготовка (этот учёт, проверка черновика #73, CI на Linux, сквозной тест);
1 КЖ — критический путь (бетон → стержни по ГОСТ → раскладка и позиции → ведомости → чертежи КЖ, затем IFC/BVBS и захватки);
2 сортамент ГОСТ; 3 доработки семейств; 4 NC/DSTV и развёртки; 5 IFC4.3, опорные модели и BCF, DWG, экспорт расчётной модели;
6 Linux/Windows и сборка выпуска; 7 совместная работа (общая папка с блокировками); 8 справка, API 1.0, аудит, бета.
Строки `docs/parity.csv` с `release=1.0` — то, что входит в этот выпуск.

Каждый пункт идёт отдельной веткой и черновым PR: код, тесты, строка в
`docs/interaction.md`, инструкция для ручной проверки на Mac. С 2026-10-20 PR сливаются после зелёного CI на macOS.
