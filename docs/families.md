# Параметрические семейства

Семейство — параметрический объект, который инженер описывает без программирования: опорные плоскости стоят на формулах, тела привязаны к плоскостям, у семейства есть типоразмеры. Размещённое семейство — один объект модели, из которого строятся обычные детали и сборка, поэтому нумерация, чертежи, ведомости и IFC работают с ним без доработки.

Код: `crates/model/src/family.rs`, команды `SetFamily`, `RemoveFamily`, `CreateFamilyInstance`, `ReplaceFamilyInstance` в `crates/commands`.

## Определение

Определение хранится в проекте (`families`, по имени), поэтому модель не зависит от файла библиотеки.

| Поле | Что задаёт |
| --- | --- |
| `placement` | `point` — в точке с поворотом; `two_points` — между двумя точками, `L` = расстояние |
| `spec` | `assembly` — одна отправочная марка с позициями деталей; `item` — одна строка изделия |
| `parameters` | имя, вид (`length`, `angle`, `number`, `integer`, `yes_no`, `material`, `profile`, `text`), группа, `of_type` (параметр типа или экземпляра), значение, формула, пределы `min`/`max` |
| `types` | типоразмеры: значения параметров типа по имени |
| `planes` | опорные плоскости: имя, ось (`X`, `Y`, `Z`), положение `at` формулой |
| `bodies` | тела: пластина (`plate`) или стержень (`member`), материал, видимость, массив |

Порядок расчёта: встроенные имена `X0`, `Y0`, `Z0` (базовые плоскости, 0) и `L`; затем параметры сверху вниз; затем плоскости сверху вниз. Каждая формула видит только то, что выше неё. Имя плоскости — значение в формулах тел, поэтому тело «стоит на плоскости», когда называет её в своих координатах. Решателя зависимостей нет: результат всегда один, а ошибка указывает на конкретную формулу.

Значение параметра берётся так: формула параметра, если она есть; иначе для параметра типа — значение типоразмера, для параметра экземпляра — значение объекта; иначе значение по умолчанию. Значение объекта может быть формулой над параметрами модели («Параметрическое моделирование»), и объект перестраивается при их изменении.

### Тела

- `plate`: пластина поперёк оси `normal`, грань на `at`, толщина `thickness` в сторону +`normal`. Точки контура — по двум другим осям: (y, z) поперёк X, (x, z) поперёк Y, (x, y) поперёк Z.
- `member`: стержень по оси от `start` до `end`, профиль — имя из каталога или параметр вида `profile`, `rotation` — поворот вокруг оси в градусах.
- `material`: марка стали («С255») или параметр вида `material`; недостающая марка и профиль копируются в проект из каталога.
- `visible`: тело есть, пока формула больше нуля.
- `array`: `count` копий со сдвигом `step` (x, y, z) каждая.

## Формулы

Те же, что в своих компонентах: числа, имена, `+ - * / ^`, скобки, `min`, `max`, `abs`, `sqrt`, `round`, `ceil`, `floor`, `if(c, a, b)`. Добавлены сравнения `< > = <> <= >=` (1 или 0, равенство с точностью 10⁻⁶), `and`, `or`, `not`, а также `sin`, `cos`, `tan`, `atan` в градусах. В `if` ошибка вычисления в невыбранной ветви не мешает: `if(n > 1, B / (n - 1), 0)` работает при n = 1.

## Объект в модели

`FamilyInstance`: семейство, типоразмер, система координат вставки (`frame` — оси X0, Y0, Z0 в модели), длина `L`, значения параметров экземпляра и построенные объекты по ролям (`body-<тело>-<копия>`, `assembly`). Роли сохраняют ID деталей при перестроении, так что марки и свойства деталей не теряются.

- Объект перестраивается, когда меняются он сам, определение семейства или параметры модели; всё одним шагом отмены.
- Геометрию и материал построенной детали напрямую изменить нельзя: меняют параметры семейства.
- Удаление объекта удаляет его детали; удаление любой его детали удаляет весь объект.
- Семейство, которое размещено в модели, удалить из проекта нельзя.
- Детали получают свойства «Семейство» и «Типоразмер».

## Образцы

`sample_families()`: «Столик опорный» (типоразмеры С-1…С-3, число рёбер 0–4, рёбра массивом) и «Стремянка» (по двум точкам; число ступеней считается формулой от `L` и шага).
