# Геометрическое ядро: решение этапа 2

Кандидат truck-modeling 0.6.0 + truck-shapeops 0.4.0 проверяется на корпусе `tests/fixtures/geometry/corpus.csv`. Корпус содержит 30 аналитических тел: кубы, выдавленный уголок, тонкие плиты, прямоугольные сквозные отверстия, объёмные пересечения и наклонные обрезки. Ожидаемые объёмы получены из независимых формул: s³, 0.72s³, 0.2s³, 0.94s³, 0.21s³, 0.32s³. Размеры s: 10, 25, 50, 100, 250 мм.

Критерий принятия: все тела имеют положительный объём, относительную ошибку ≤1e-6, замкнутый B-rep и ориентированную сетку. Для сетки отдельно проверяется, что каждое ребро встречается ровно дважды в противоположных направлениях. Данные измерений сохраняются тестом при установленном OPEN_BIM_GEOMETRY_REPORT. Решение окончательно после обязательных команд этапа и сохранённого отчёта.

## Границы

- Используем точные B-rep-ссылки truck. Bounding box не заменяет boolean-операции.
- Внутри тела координаты локальные f64; origin хранится отдельно. f32 создаётся только для локальной display-сетки. Отдельный тест использует мировое смещение 1e6 мм и толщину 0.005 мм.
- Абсолютный допуск моделирования: 0.0001 мм. Минимальный размер — больше 0.001 мм. Ввод ограничен по числу вершин и координатам; неположительные, нечисловые и вырожденные параметры отклоняются.
- Устойчивость касательных/копланарных boolean не гарантируется: возвращается типизированная ошибка, если результат не прошёл проверки. Повреждённое тело не выдаётся как результат.
- Корпус не доказывает точность криволинейных отверстий и произвольных NURBS. Их аналитические и независимые проверки добавляются до использования в последующих этапах.
- Любое изменение топологии создаёт новые внутренние edge/face ID; ссылки домена на объект сохраняются независимо. Стабильные ссылки размерных привязок требуют явного алгоритма сопоставления, а не предположения о постоянстве ID truck.

## Найденные дефекты и меры

Пересечение №2 первоначально имело замкнутую точную оболочку, но после объединения вершин сетки оставались вырожденные треугольники. Адаптер удаляет такие треугольники и затем проверяет замкнутость; объёмы сверяются с прежними эталонами, без ослабления допуска. Robust triangulation применяется для кривых пересечения.

truck-shapeops по умолчанию включал ненужный VTK exporter через truck-meshalgo. Локальный patch отключает этот feature и ограничивает private test-only модуль конфигурацией cfg(test); математические алгоритмы сохранены без изменений. Происхождение и точные изменения записаны в `vendor/truck-shapeops/PATCH.md`. Так исключаются устаревшие nom/quick-xml и предупреждение о неиспользуемом тестовом типе, а основной тестовый корпус продолжает проверять операции.

## Проверенное решение

truck принят для реализованного подмножества операций: 30/30 тел прошли корпус; максимальная относительная ошибка объёма 1.863e-16. Измерения: tests/fixtures/geometry/measured.csv. Все четыре обязательные команды имеют exit 0 без предупреждений. Слияние вершин переводит абсолютный допуск в нормализованные координаты upstream, поэтому допуск не увеличивается вместе с размером тела.
