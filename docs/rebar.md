# Арматурные стержни

Пункт 1.2 плана выпуска 1.0. Код: `crates/model/src/rebar.rs` (нормы, раскладка,
перестроение), `crates/desktop/src/interaction/rebar.rs` (инструменты вкладки
«Армирование»), проверки: `crates/desktop/tests/rebar_bars.rs`, `rebar_tab.rs`.

## Классы арматуры

| Класс | Rs,n | Rs | Rsc | Rsw | Поверхность | Ø, мм |
|---|---|---|---|---|---|---|
| А240 | 240 | 210 | 210 | 170 | гладкая | 6–40 |
| А400 | 400 | 350 | 350 | 280 | периодическая | 6–40 |
| А500С | 500 | 435 | 435 | 300 | периодическая | 6–40 |
| В500С | 500 | 435 | 415 | 300 | холоднодеформированная | 4–16 |
| А600 | 600 | 520 | 470 | — | периодическая | 10–40 |

Сопротивления в МПа по СП 63.13330.2018, табл. 6.13–6.14 (Rsc при длительном
действии нагрузки), сортамент по ГОСТ 34028-2016. Диапазоны диаметров нужно
сверить с текстом стандарта при подготовке каталога (этап 2 плана).

Масса 1 м стержня берётся номинальная: площадь номинального сечения на 7850 кг/м³,
три знака после запятой (Ø16 → 1,578 кг/м). Ведомость считает массу по длине
стержня по оси с учётом гибов.

## Формы, гибы и крюки

- Стержень хранится как ломаная по точкам пересечения осей прямых участков.
  Длина заготовки: длина ломаной минус на каждом гибе на угол θ две касательные
  R·tg(θ/2) плюс дуга R·θ, где R = (dоправки + ds)/2.
- Наименьший диаметр оправки: гладкие стержни 2,5·ds при ds < 20 и 4·ds при
  ds ≥ 20; периодического профиля 5·ds и 8·ds. Его можно задать больше.
- Концы: прямой, отгиб 90° (прямой участок 10·ds), крюк 135° (6·ds, по
  умолчанию у хомутов, оба крюка заводятся в ядро у первого угла), крюк 180°
  (3·ds). Длину прямого участка можно задать.
- Отгибы продольных стержней балки заводятся внутрь сечения, у сеток к
  противоположной грани. У стержней по точкам: в плоскости крайних участков,
  у прямого стержня вниз (у вертикального вдоль +X).

## Анкеровка и нахлёст (СП 63.13330.2018, 10.3.24–10.3.31)

- Rbond = η1·η2·Rbt; η1 = 1,5 для гладкой, 2,0 для холоднодеформированной,
  2,5 для горячекатаной периодического профиля; η2 = 1,0 при ds ≤ 32 и 0,9 при
  ds = 36 и 40.
- l0,an = Rs·As/(Rbond·us) = Rs·ds/(4·Rbond).
- lan = α·l0,an·As,cal/As,ef, α = 1,0 для растянутых, 0,75 для сжатых;
  не менее 0,3·l0,an, 15·ds и 200 мм.
- ll = α·l0,an·As,cal/As,ef, α = 1,2 для растянутых, 0,9 для сжатых (не более
  50 % стыкуемых стержней в одном сечении); не менее 0,4·α·l0,an, 20·ds и 250 мм.
- Rbt берётся из класса бетона детали-основы («Бетон В25»), при неизвестном
  классе В25. Окно «Армирование» показывает lan и ll для выбранной детали.

Если стержень длиннее длины поставки (по умолчанию 11 700 мм), он делится на
равные куски с нахлёстом ll на растяжение. Отгибы и крюки остаются только на
крайних концах.

## Перестроение

Наборы, поставленные в деталь («Продольные», «Поперечные», «По грани»), хранят
правило раскладки: защитный слой, шаг, число стержней на грани, длину поставки.
После каждой команды ядро сравнивает деталь-основу, её сечение и материал с
прежним состоянием и при изменении строит стержни заново. Если новые размеры
не вмещают арматуру с заданным защитным слоем, команда отменяется с сообщением.
При удалении детали её наборы удаляются. Стержни по точкам не перестраиваются.
