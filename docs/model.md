# Модель BIM

Все объекты имеют глобально уникальный ObjectId (u64). ID 0 запрещён; next_id строго больше любого существующего ID. Ключ карты обязан совпадать с ID объекта. Десериализатор отвергает повторяющиеся JSON-ключи вместо молчаливой перезаписи.

Единицы домена — миллиметры, плотность — кг/м³. Локальная система Frame задаётся origin и правым ортонормированным базисом. Ось local z определяет длину балок и колонн; контур плиты лежит в local xy. Изменение позиции не меняет ID.

Новый проект в приложении начинается со стали С255 (ГОСТ 27772) и пяти профилей ГОСТ: 30Б1 (ГОСТ Р 57837), L100×8, [20П, труба 114×4,5, Гн 150×100×6, плюс брус 100×50. Остальной сортамент берётся из встроенного каталога (`open_bim_model::library`): двутавры ГОСТ Р 57837, 26020 (с таврами из них), 8239 и СТО АСЧМ 20-93, швеллеры У и П ГОСТ 8240, уголки ГОСТ 8509 и 8510, трубы ГОСТ 10704 (10–1420 мм) и ВГП ГОСТ 3262, гнутые профили ГОСТ 30245, стали ГОСТ 27772 (С235–С440) и 09Г2С. `Project::default` в коде по-прежнему содержит шесть аналитических тестовых сечений без скруглений (I 300×150×8×12 и др.) — на них написаны геометрические тесты. Источник записан в каждом профиле. Площади сверяются с независимыми числовыми fixtures; итоговая геометрия кривых проверяется до её использования.

Материал, профиль и геометрия хранятся по ссылкам и сериализуются. Сборка явно содержит главный элемент, непосредственно принадлежащие детали и дочерние сборки. Один объект не может принадлежать двум сборкам. Итеративный обход проверяет циклы без рекурсивного роста стека.

Контрольный каркас содержит 4 колонны, 2 балки, пластину 400×400×20, оси, уровни и одну сборку. Ожидаемая масса без вырезов/крепежа — 1119.3472 кг при плотности 7850 кг/м³. Числовые, строковые и логические пользовательские свойства сохраняются без изменения идентичности.

`Project::from_json` проверяет модель после разбора; `Project::to_json` запрещает выпуск некорректной модели. Формат файла проекта с версией, атомарной записью и миграциями реализуется на этапе 5.
