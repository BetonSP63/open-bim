2026-10-12. Настоящее приложение eframe/wgpu, Apple M5, Metal, framebuffer 2560×1600. Снимки не макеты. [Логи запуска](launch-results.json), [коды обязательных проверок](command-results.json).

| Камера мышью и клавиатурой | pass | UI-кнопка «Сверху» дала ортографию; клавиши 1, Right, Shift+Left, + изменили вид, ориентацию, положение и масштаб; CPU roundtrip всех четырёх видов |

Четыре regression-теста renderer дополнительно проверяют замкнутую ориентированную сетку полых профилей, свободный просвет, повторное использование трёх сеток на семь объектов и picking при координатах около 900 миллионов мм. Полный workspace: 33 теста pass; один child-helper ignored при обычном запуске и вызывается настоящим crash-тестом persistence. Build/test/fmt/clippy exit 0, предупреждений нет.

UI smoke выполнен через cua_repl в локальной временной .app-оболочке того же debug-бинарника. Ранее выявлена нестабильность автоматически назначенных ID строк; после push_id(ObjectId) повторно подтверждены независимые флажки балки #12 и пластины #14. Снимки UI smoke присутствуют в протоколе разговора. Mouse orbit/pan используют реальные pointer delta; все функции камеры проверены тестами, wheel и клавиатурные действия подключены к той же камере.

Ограничения: без крышек сечения; CHS графически сегментирован; 100k ещё не измерено; другие GPU/ОС ещё не проверены. Полный паритет с Tekla остаётся открытым.
