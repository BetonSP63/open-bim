# Проверка деталировки в настоящем GUI

Проверено в нативном Open BIM на macOS ARM64, Apple M5, Metal, через реальные элементы интерфейса. Это не снимки браузерного макета.

Журнал `gui-flow.json` содержит 15 операций. `gui-project.obim` и `connection.obim` сохраняют итоговое соединение. `gusset-hole.obim` сохраняет промежуточную косынку с отверстием и толщиной 16 мм.

Также через GUI выполнены undo и redo сварного шва. Независимая проверка Python подтверждает:

- SHA-256 канонического payload: `eb254a1160466f6e73f73acb9645a7ebdf038fd1ec6da46c7b10ea8769b39528`.
- Сохранённая и повторно открытая модели равны.
- Undo вернул состояние до шва; redo восстановил итоговый SHA-256.
- Роли, размеры и связи всех объектов совпадают с введёнными значениями.

`verification-results.json` содержит отдельно рассчитанные эталоны массы и длины шва. Тест `crates/steel/tests/gui_fixture.rs` загружает настоящий сохранённый проект, проверяет массы с относительной ошибкой ≤1e−6 и строки болтов/шва из `fabrication_rows`. Тест прошёл.

Наблюдаемое ограничение: пересборка сцены соединения занимает около 16 секунд, в том числе после изменения только данных шва. Это функциональная проверка, а не подтверждение приемлемой производительности. Оптимизация требуется до итогового завершения.
