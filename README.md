# Open BIM

Открытое desktop-приложение на Rust для моделирования и деталировки строительных конструкций. Разработка начинается со стали на macOS ARM64, затем добавляются бетон и арматура.

**Текущее состояние: геометрия, модель, хранение и GPU-вид; инструменты моделирования проходят проверку. Полный паритет с Tekla Structures не подтверждён.** Подтверждённое покрытие и открытые задачи перечислены в [матрице](docs/parity.csv).

## Запуск

Требования: macOS ARM64, Rust 1.99.0 (rustup), доступ к crates.io для первой сборки. После загрузки зависимостей приложение работает офлайн.

```sh
cargo run --locked -p open-bim-desktop
```

Если системный линкер не распознаёт `arm64e.x1` в SDK 27, а SDK 26.5 установлен, задайте перед командами локальную переменную процесса:

```sh
export SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
```

На текущем хосте сборка проверяется с этой настройкой. На исправной системе она не требуется.

## Проверки

```sh
cargo build --workspace --locked
cargo test --workspace --locked
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
```

Проверены геометрическое ядро, модель BIM, транзакции undo/redo, формат проекта с аварийным восстановлением и GPU-вид. Для контрольного каркаса добавьте `-- --example` к команде запуска. В интерфейсе работают камера, выбор, видимость и сечение, числовое создание осей, балок, колонн и контурных плит, перемещение, копирование, поворот, зеркало, свойства и сохранение/открытие `.obim`. Автоматические проверки инструментов проходят; полная проверка этапа 7 ещё продолжается. См. [управление 3D-видом](docs/viewport.md).

См. [архитектуру](docs/architecture.md), [источники зависимостей](docs/dependencies.md) и [лицензию](LICENSE). Название Tekla используется только для описания цели функционального сравнения; проект независимый.
