# Open BIM

Открытое desktop-приложение на Rust для проектирования стальных и железобетонных конструкций: модель, узлы, чертежи КМ/КМД по ГОСТ Р 21.101-2026, спецификации и обмен IFC. Цель — чтобы инженер-конструктор мог работать без покупки дорогих коммерческих программ. Лицензия Apache-2.0.

**Состояние (октябрь 2026):** выпущена 0.1.0 (сталь, macOS ARM64), на `main` готовится 1.0. Это ещё не полный аналог коммерческих программ: что проверено и что открыто — в [матрице](docs/parity.csv) (30 строк проверены, 14 открыты).

## Что уже умеет

- **Моделирование:** оси и уровни, балки, колонны и пластины по точкам с привязками, положение детали, копирование специальное, фильтры и группы выбора, файлы свойств, параметры модели и связанные размеры.
- **Сортамент:** таблицы ГОСТ 8239, Р 57837, 8240, 8509, 8510, 30245, 10704 и марки стали; пользовательские и сварные сечения.
- **Узлы:** каталог компонентов (опорная плита, торцевая пластина, уголки, шарнир на пластине, рёбра, стык, вут, столик), автосоединения, свои компоненты по формулам; болты, сварка по ГОСТ со знаками ГОСТ 2.312.
- **Параметрические семейства:** опорные плоскости, формулы, типоразмеры, вложенные семейства ([описание](docs/families.md)).
- **Документация:** нумерация с сериями, общие виды, чертежи сборок и деталей, редактор чертежей, мастер чертежей, менеджер документов, спецификации и ведомости по ГОСТ, изменения и электронный пакет; PDF, DXF, SVG, CSV.
- **Обмен и производство:** IFC4 и IFC4.3 (экспорт, импорт из других программ, в том числе мостов и дорог IFC4.3), NC/DSTV `.nc1` (основное подмножество).
- **Прочее:** проверка коллизий, расчётная модель (нагрузки, узлы, связи; без расчёта), объектный API, пакетный режим и плагины, основа бетона, армирования и опалубки, 100 000 объектов в 3D-виде, полное управление с клавиатуры.

## План 1.0

Критический путь — железобетон (КЖ) по ГОСТ: формы стержней, позиции, ведомости и чертежи КЖ. Затем полный сортамент, NC и развёртки, опорные модели и BCF, DXF/DWG, сборки для Linux и Windows, совместная работа через общую папку с блокировками, публичный API. Подробности: [бэклог](docs/backlog.md), [выпуски](docs/releases.md), [аудит 0.1.0](docs/final-audit.md).

## Запуск

Требования: macOS ARM64, Rust 1.99.0 (rustup), доступ к crates.io для первой сборки. После загрузки зависимостей приложение работает офлайн.

```sh
cargo run --locked -p open-bim-desktop
```

Если системный линкер не распознаёт `arm64e.x1` в SDK 27, а SDK 26.5 установлен, задайте перед командами локальную переменную процесса:

```sh
export SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
```

На текущем хосте сборка проверяется с этой настройкой. На исправной системе она не требуется.

## Сборка приложения macOS

```sh
scripts/package-macos.sh
```

Создаёт `dist/Open BIM.app` и zip-архив (без подписи и нотаризации, см. [релизы](docs/releases.md)).
Управление с клавиатуры: ⌘P — поиск команд, F1 — все горячие клавиши, F2/F3/F4 — модель/чертежи/ведомости.

## Пример стального выпуска

Каркас → соединения → нумерация → комплект чертежей → спецификации на модели
`tests/fixtures/steel_release/source.obim` (16 деталей, 6 узлов, созданных в GUI):

```sh
cargo run --release --locked -p open-bim-desktop -- --open tests/fixtures/steel_release/source.obim
```

В приложении: **F4 Ведомости** → «Сборки по заводским швам» → «Выпустить комплект»
(общий вид A1, чертежи сборок и деталей по позициям, PDF и CSV в папку `release`);
**F3 Чертежи** — редактирование листов; **⌘K** в модели — нумерация и коллизии;
⌘S — сохранить. Тот же выпуск без GUI:

```sh
cargo run --release --locked -p open-bim-reports --bin open-bim-release -- tests/fixtures/steel_release/source.obim release --auto-assemblies --save release/project.obim
```

Подробности: [выпуск стали](docs/steel-release.md), [чертежи](docs/drawings.md).

## Проверки

```sh
cargo build --workspace --locked
cargo test --workspace --locked
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
```

Проверены геометрическое ядро, модель BIM, транзакции undo/redo, формат проекта с аварийным восстановлением и GPU-вид. Для контрольного каркаса добавьте `-- --example` к команде запуска. В интерфейсе работают камера, выбор, видимость и сечение, числовое создание осей, балок, колонн и контурных плит, перемещение, копирование, поворот, зеркало, свойства и сохранение/открытие `.obim`. Инструменты этапа 7 проверены автоматическими тестами и сценариями настоящего GUI. См. [моделирование](docs/modeling.md). См. [управление 3D-видом](docs/viewport.md).
