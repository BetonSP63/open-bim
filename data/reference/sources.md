# Источники и проверка справочных данных

Все таблицы собраны 2026-10-20 из открытых веб-копий стандартов. Ни одно число не
придумано и не интерполировано. Если копия содержит явную опечатку, значение либо
взято из второй независимой копии, либо оставлено как напечатано (или пустым), и в
обоих случаях это записано в колонке `notes`. Веб-копии неофициальные: перед
использованием в расчётах сверяйте значения с официальным изданием стандарта.

Методы проверки (скрипты лежали вне репозитория):

- **Проверка массы:** `mass_kg_m ≈ area_cm2 × 0,785` (плотность 7850 кг/м³) с
  допуском 2 %.
- **Точная геометрия:** площадь и моменты инерции считались по контуру сечения
  с галтелями и скруглениями (формула Грина) и сравнивались с напечатанными.
- **Тождества:**
  - `W = I / y_max`;
  - `i = √(I/A)`;
  - для равнополочного уголка `Ix0 + Iy0 = 2·Ix`;
  - для швеллера `Wy = Iy / (b − z0)`.
- **Вторая копия:** построчное сравнение со вторым независимым набором данных
  (см. «Вторые источники»).
