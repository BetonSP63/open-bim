# Логика моделирования эталонной программы и статус Open BIM

Обзор того, как ведут себя распространённые коммерческие аналоги (далее —
«эталонная программа») в восьми областях, и что из этого уже есть в Open BIM.
Описание составлено по открытой пользовательской документации на 2026-10-20 и
пересказано своими словами; значения по умолчанию указаны только там, где их
называет документация.

Статус Open BIM взят из [docs/interaction.md](../../docs/interaction.md),
[docs/reference-docs-comparison.md](../../docs/reference-docs-comparison.md),
[docs/backlog.md](../../docs/backlog.md), [docs/parity.csv](../../docs/parity.csv)
и [docs/steel-release.md](../../docs/steel-release.md).

Обозначения: ✅ есть · ⚠ частично · ❌ нет.

## 1. Положение детали и уровни

- **Пользователь:** в свойствах балки или колонны выбирает «В плоскости»
  (середина / справа / слева), «Поворот» (верх / спереди / сзади / снизу + угол),
  «По глубине» (середина / спереди / сзади), смещения и смещения концов Dx/Dy/Dz.
  Для колонн — уровни Низ/Верх.
- **Программа:** балка задаётся опорной линией из двух точек, колонна — одной точкой.
  Параметры положения сдвигают профиль относительно линии, саму линию не двигают.
  Угол поворота на экране меняется ручкой с шагом 5° (Shift снимает шаг).
  Уровни колонн — в глобальной Z.
- **Привязка к уровням сетки:** «Авто» (ближайший уровень) / конкретный уровень /
  «Нет», для каждого конца отдельно, со смещением. Колонны и стены — верх и низ;
  балки — начало и конец; плиты — только верх. При изменении отметки уровня деталь
  переезжает вместе с болтами и вырезами. При копировании привязка сохраняется для
  концов, чьи уровни нашлись в новом месте.
- **Open BIM:** ✅ в плоскости / поворот / по глубине, смещения, Dx концов; ✅ Низ/Верх
  колонны как глобальная Z; ❌ привязка к уровням сетки.

## 2. Файлы свойств (сохранить / загрузить)

- **Пользователь:** сохраняет набор значений диалога под именем и загружает его потом.
  Загруженные значения применяются к выбранным объектам или к создаваемым.
- **Программа:** файлы лежат в папке `attributes` модели, расширение зависит от типа
  объекта (балка, колонна, пластина, болт, шов, нумерация, вид…). Файл `standard`
  подставляется по умолчанию. Поиск идёт по цепочке папок
  модель → проект → организация → среда → роль → система; побеждает первый
  найденный файл.
- **Open BIM:** ❌ нет.

## 3. Привязки

- **Пользователь:** включает переключатели привязок. Во время команды может правой
  кнопкой выбрать одну привязку только для следующей точки. Tab перебирает кандидатов,
  Ctrl+щелчок ставит временную опорную точку, Shift фиксирует направление,
  X/Y/Z блокирует координату, O включает орто.
- **Программа:** два главных переключателя («опорные линии и точки» и
  «геометрические линии и точки») имеют высший приоритет; без них привязки нет.
  Остальные переключатели: точки, концы, центры, середины, пересечения,
  перпендикуляр, параллель, продолжения линий, любая точка, ближайшая, линии.
  Есть сетка привязки для «любой точки». Резиновая линия орто окрашивается по оси.
- **Open BIM:** ✅ главные переключатели, концы, середины, пересечения, перпендикуляр,
  ближайшая, свободная точка, Tab, временная точка по Ctrl; ⚠ орто; ❌ центры,
  параллель, продолжения, линии, глубина привязки, разовое переопределение,
  Shift-фиксация, X/Y/Z, клавиши R/A/G.

## 4. Копирование и перемещение

- **Пользователь:** обычное копирование и перемещение по двум точкам (команда
  повторяется до Esc). Кроме того, есть специальное копирование:
  - линейно — dX/dY/dZ и число копий;
  - с поворотом — центр, угол, число копий, dZ;
  - зеркально;
  - в другую плоскость — по три точки исходной и целевой плоскостей;
  - на другой объект;
  - всё содержимое на другой объект;
  - из другой модели — по стадиям.
- **Программа:** показывает предпросмотр копий. Документация называет предел
  предпросмотра — 1000 объектов. Перетаскивание с Ctrl включается в настройках.
- **Open BIM:** ✅ перемещение и копирование по двум точкам с повтором, зеркало по
  двум точкам, поворот; ❌ специальное копирование, перетаскивание, буфер обмена.

## 5. Выбор и фильтры

- **Пользователь:** использует щелчок, рамку слева направо (только целиком внутри) и
  справа налево (касающиеся), Shift (добавить), Ctrl (переключить), Ctrl+A,
  Alt+P (предыдущий выбор), выбор по идентификатору, Alt + рамка (только ручки).
- **Программа:**
  - Переключатели выбора ограничивают типы объектов. Режим «выбор касанием» по
    умолчанию выключен.
  - Фильтр выбора — это именованный набор строк «категория — свойство — условие —
    значение» с И/ИЛИ и скобками. Новые строки по умолчанию выключены.
  - Поддерживаются подстановки `*` и `?`. Имена фильтров чувствительны к регистру.
- **Open BIM:** ✅ щелчок, Shift, Ctrl, Alt, рамка в обе стороны, Ctrl+A, переключатели
  для деталей, сборок, групп болтов, швов и осей; ❌ фильтры, Alt+P, подсветка под
  курсором, переключатели компонентов, вырезов и точек.

## 6. Нумерация

- **Пользователь:** задаёт деталям и сборкам серию — префикс и начальный номер
  (например, P и 1001 → P1001). Запускает нумерацию перед чертежами деталей и сборок.
- **Программа:**
  - Сравнивает объекты только внутри серии.
  - Одинаковыми считаются детали с одинаковыми геометрией (в пределах допуска),
    профилем, материалом, отделкой, укорочением и серией. Класс на номер не влияет.
  - Настройки:
    - перенумеровать всё;
    - переиспользовать освободившиеся номера;
    - сверять со стандартными деталями;
    - для изменённых объектов — сравнить со старыми / взять новый номер / по
      возможности сохранить номер;
    - какие признаки сравнивать (отверстия, имя, ориентация, швы и др.);
    - допуск.
  - Пример: три одинаковые балки получают P1. Одну изменили — P2. Вернули как было:
    «сравнить» даёт P1, «сохранить» — P2, «новый» — P3.
  - Устаревшая нумерация помечается «?».
- **Open BIM:** ⚠ детерминированная эквивалентность (`crates/numbering`), позиции
  P0001/A0001; ❌ пользовательские серии и префиксы, режимы и допуск.

## 7. Чертежи

- **Пользователь:** выбирает объекты и создаёт чертежи следующих типов:
  - общий вид;
  - деталь;
  - сборка;
  - литой элемент;
  - план анкерных болтов;
  - мультичертёж;
  - клон.

  Чертежами управляет в отдельном менеджере документов.
- **Программа:**
  - Модель — единственный источник. Для одинаковых сборок создаётся один чертёж.
  - Чертежи ассоциативны и обновляются при изменении модели, ручные правки
    сохраняются.
  - Менеджер показывает устаревшие чертежи. В нём есть блокировка, заморозка, выдача
    и ревизии.
  - Каталог мастер-чертежей объединяет шаблоны клонирования, сохранённые настройки и
    наборы правил. При создании по умолчанию подбирается лучший шаблон, затем лучшие
    сохранённые настройки, затем текущие. Обзор перед созданием по умолчанию
    выключен. Имя чертежа — до 32 символов.
- **Open BIM:** ✅ общие виды, чертежи деталей и сборок, ревизии, PDF/DXF; ❌ литые
  элементы (бетон отложен), менеджер документов, мастер-каталог, наборы правил,
  клонирование.

## 8. Каталог компонентов

- **Пользователь:** открывает каталог (Ctrl+F), ищет компонент, затем указывает
  главную деталь, вторичные детали и завершает средней кнопкой.
- **Программа:**
  - Поиск не зависит от регистра, и в нём поддерживаются подстановки и ключи
    `tag:` / `group:` / `type:`.
  - Есть группы «Недавние» (12 последних), «Узлы», «Детали» и другие, а также
    пользовательские группы.
  - Символ компонента показывает состояние: зелёный — создан, жёлтый — с замечаниями,
    красный — не создан.
  - Параметр «направление вверх» (±x/±y/±z) поворачивает узел.
  - Правила автоподстановки свойств и автоматической расстановки узлов.
- **Open BIM:** ⚠ три параметрических узла (опорная плита, торцевая пластина,
  уголок) с шаблонами; ❌ каталог, поиск, группы, символ состояния, направление
  вверх, автоправила.

## Чего нет в открытой документации

- Значения по умолчанию для положения детали и для переключателей привязок.
- Полный список параметров нумерации с их значениями по умолчанию.
- Формат файлов мастера чертежей.
